# برق للتحميل — Barq Download (Android)

مدير تحميل لأندرويد بنفس مميزات برنامج الويندوز **Ezoo Download** (نسخة 1.0.12). التطبيق مكتوب من الصفر بـ Kotlin، والمميزات أخذناها من تحليل البرنامج الأصلي.

> تطبيق مستقل، مش تابع لـ Ezoo Tech، وما فيهوش أي كود من البرنامج الأصلي.

## التحميل
- **[BarqDownload-arm64-v8a.apk](../../releases/download/latest/BarqDownload-arm64-v8a.apk)**: لأغلب الموبايلات الحديثة.
- **[BarqDownload-armeabi-v7a.apk](../../releases/download/latest/BarqDownload-armeabi-v7a.apk)**: للأجهزة القديمة وبعض بوكسات التلفزيون.

كل push على `main` بيبني نسخة جديدة لوحده (Actions ← Build APK). النسخة الجديدة بتتثبت فوق القديمة على طول، لأنها موقّعة بنفس المفتاح.

## ملاحظات
- الملفات بتتحفظ في `Download/Barq/<التصنيف>`. لو عايز تحفظ في أي مكان تاني (أو كارت ميموري): الخيارات ← الحفظ ← «السماح بالوصول إلى كل الملفات».
- لو الموبايل بيوقف التحميل والشاشة مقفولة: الخيارات ← عام ← «البطارية: بلا قيود».
- محمّل الفيديو بيحدّث نفسه كل كام يوم، علشان يوتيوب بيتغير كتير.

## البناء
Gradle 8.9 و AGP 8.5 و Kotlin 1.9.24 و Jetpack Compose. ملف `app/barq.keystore` مفتاح توقيع للتطوير بس (باسورده `android`)، ووظيفته إن كل نسخة تتثبت فوق اللي قبلها.
